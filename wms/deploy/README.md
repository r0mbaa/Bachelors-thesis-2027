# deploy — стенд одной командой

```sh
cd wms
docker compose up --build
```

Поднимаются PostgreSQL, `core`, `planner` и Caddy. Caddy — единственная точка входа, он сразу отдаёт HTTPS (NFR-SEC-05, NFR-SEC-07). Сертификат выпускает собственный удостоверяющий центр Caddy: интернет и ручной выпуск не нужны, IP-адрес в локальной сети тоже поддерживается.

| Путь | Куда |
| --- | --- |
| `https://<хост>/api/…`, `/actuator/health`, `/swagger-ui.html` | `core` |
| `https://<хост>/check/` | Проверка камеры и распознавания QR (§1.5) |
| `http://<хост>/ca.crt` | Корневой сертификат для установки на телефон |
| всё остальное по HTTP | Перенаправление на HTTPS |

`planner` наружу не публикуется: его вызывает только `core`.

## Проверка с телефона

Браузер даёт доступ к камере только по HTTPS, а на `localhost` разработчика это ограничение не проявляется. Поэтому проверять нужно с того телефона, который будет на защите (§1.5, §15.5, шаг 0).

1. Узнать IP компьютера в локальной сети и запустить стенд с ним: `WMS_HOST=192.168.1.20 docker compose up --build` (или записать `WMS_HOST` в файл `.env` рядом с `docker-compose.yml`).
2. На телефоне открыть `http://192.168.1.20/ca.crt` и установить сертификат как доверенный:
   - Android: «Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС»;
   - iOS: установить профиль, затем «Настройки → Основные → Об этом устройстве → Доверие сертификатам» и включить его.
3. Открыть `https://192.168.1.20/check/`: «Защищённое соединение: да», «Включить камеру», навести на любую этикетку из `GET /api/v1/labels/...`.

Удостоверяющий центр хранится в томе `caddy-data`. Пока том жив, доверие на телефоне сохраняется между перезапусками; `docker compose down -v` его удаляет.

## Переменные

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `WMS_HOST` | `localhost` | Имя или IP, под которым стенд виден в сети, — на него выписывается сертификат |
| `WMS_ADMIN_PASSWORD` | `change-me-now` | Пароль пользователя `admin`, создаётся на пустой БД. Для демонстрации задайте свой |
| `WMS_JWT_SECRET` | пусто | Ключ подписи токенов, Base64 от 32 байт; пусто — новый ключ при каждом запуске `core` |
| `WMS_HTTP_PORT`, `WMS_HTTPS_PORT` | `80`, `443` | Если порты на машине заняты |

## Образы

Один [`Dockerfile`](../Dockerfile) на оба сервиса, модуль выбирает аргумент `SERVICE`. Сборка многоэтапная: Gradle в JDK-образе собирает `bootJar`, jar раскладывается на слои Spring Boot, в итоговый образ на JRE Alpine слои копируются от редко меняющихся к часто меняющимся. При правке кода пересобирается только последний слой. Кэш Gradle подключается кэш-монтированием BuildKit и переживает пересборку. Процесс в контейнере запущен не от root.
