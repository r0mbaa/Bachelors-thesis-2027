# core/print — печатные формы

PDF для печати на обычном офисном принтере: QR-этикетки и маршрутный лист.

**Требования:** FR-M1-12, FR-M11-03 (маршрутный лист), FR-M11-04 (PDF), §11.3.

| Запрос | Что печатается | Роль |
| --- | --- | --- |
| `GET /api/v1/labels/locations?warehouse=&row=&zone=` | Этикетки ячеек склада, ряда или зоны в порядке адресов (FR-M1-12) | `WAREHOUSE_ADMIN`, `RECEIVER` |
| `GET /api/v1/labels/skus?articles=` | Этикетки товаров `SKU:…`; без списка — весь справочник | `WAREHOUSE_ADMIN`, `RECEIVER` |
| `GET /api/v1/labels/containers?warehouse=` | Этикетки тары `CNT:…` | `WAREHOUSE_ADMIN` |
| `GET /api/v1/labels/workers?warehouse=` | Бейджи сборщиков `WRK:…` для входа в терминал | `WAREHOUSE_ADMIN`, `SYSTEM_ADMIN` |
| `GET /api/v1/tasks/{number}/route-sheet` | Маршрутный лист задания с QR `TSK:…` | `DISPATCHER`, `WAREHOUSE_ADMIN`, `PICKER` |

## Этикетки

Лист A4 из 24 этикеток 70 × 37 мм (3 × 8) — самый распространённый формат самоклеящихся листов. Слева QR, справа крупно ряд и секция, ниже ярус и позиция, внизу код целиком: по нему вводят вручную, если этикетка не сканируется (FR-M10-04b). За раз печатается до 2 400 этикеток (100 листов), склад целиком печатается по рядам или зонам.

QR кодируется с уровнем коррекции Q: он восстанавливает до 25 % модулей, а этикетка на складе мнётся и пачкается. Модули рисуются векторными прямоугольниками, соседние тёмные модули строки сливаются в один. Поэтому печать чёткая на любом принтере, а файл лёгкий.

## Маршрутный лист

Шапка: номер задания, тара, заказы по отделениям тележки, сборщик, время формирования и алгоритм, которым построен маршрут. Таблица: шаги в порядке обхода — ячейка, ярус, артикул, наименование, количество, отделение, клетка для отметки. Длинные задания переносятся на следующие страницы с нумерацией «Стр. N из M». Время выводится в часовом поясе склада `wms.print.zone` (по умолчанию `Europe/Moscow`).

## Решения

- **PDFBox напрямую, а не HTML → PDF** (§12.6 предлагал openhtmltopdf и Thymeleaf). Этикетка — точная сетка в миллиметрах под конкретный формат листа, её проще и надёжнее рисовать координатами, чем верстать HTML. openhtmltopdf сам построен на PDFBox, так что стек тот же.
- **Шрифт DejaVu Sans** приходит зависимостью `net.sourceforge.jeuclid:dejavu-fonts` и встраивается подмножеством. Без встроенного шрифта кириллица в PDF не отображается; лицензия DejaVu разрешает распространение.
- **XLSX** (FR-M11-04) и остальные формы FR-M11-03 — приходный ордер, лист комплектации, накладная, акты — пока не сделаны.

## Проверка

Тесты проверяют печать так, как её прочтёт сканер: страница рендерится в картинку, каждая этикетка вырезается по разметке листа, и её QR распознаётся ZXing. Все 24 кода листа должны совпасть с кодами ячеек.
