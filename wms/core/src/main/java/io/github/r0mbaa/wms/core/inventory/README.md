# core/inventory — M4. Остатки, движения, инвентаризация

Остатки по парам «ячейка × SKU», неизменяемый журнал движений, инвентаризация и расхождения.

Держит инварианты §11.2: `quantity >= 0`, `reserved_quantity <= quantity`, журнал движений недоступен для `UPDATE`/`DELETE` прикладной роли БД.

**Требования:** FR-M4-01 .. FR-M4-10.
