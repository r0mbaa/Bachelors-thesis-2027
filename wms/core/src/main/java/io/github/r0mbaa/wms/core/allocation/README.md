# core/allocation — M6. Аллокация и резервирование (состояние)

Транзакционная часть M6: выбор конкретных ячеек под строки заказа и резервирование остатка.

Алгоритмическая часть — в модуле `planner-engine`, пакет `engine.allocation`; снаружи она доступна через сервис `planner`. Разрез намеренный: состояние резервов принадлежит `core`, правило выбора — планировщику (§12.2).

**Требования:** FR-M6-01 .. FR-M6-06. **Постановка:** §8.4. **Конкурентность:** `@Version` и повтор транзакции при `OptimisticLockException`.
