# core/layout — M15. Конструктор склада, серверная часть

Хранение планировки с версионированием, импорт и экспорт в JSON (FR-M15-10), REST для редактора, материализация ячеек в таблицы учёта после сохранения версии.

Вся геометрия, то есть генерация ячеек (FR-M15-05), построение графа (§8.7), валидация (FR-M15-07), классификатор топологии (FR-M15-08) и параметрический мастер (FR-M15-09), живёт в библиотеке `layout`. Этот пакет её вызывает и ничего не вычисляет сам. Благодаря этому стенд `research` получает те же ячейки и тот же граф без БД.

Редактор и трёхмерная сцена — в модуле `web`. Принцип разделения: редактирование только в 2D, отображение в 3D (§7.15.1).

**Требования:** FR-M15-01 .. FR-M15-31.
