# core — учётное ядро

Spring Boot, Java 21. Stateful: владеет PostgreSQL. Профиль — I/O-bound, короткие транзакции.

Отказ `core` останавливает работу склада, поэтому частота изменений здесь низкая после стабилизации (§12.2).

## Транзакционная целостность

Основную работу выполняет СУБД, фреймворк лишь управляет границами транзакций (§12.2): CHECK-ограничения против отрицательных остатков, `@Version` на конкурентной аллокации, `PESSIMISTIC_WRITE` в детерминированном порядке строк на резервировании волны, уникальный индекс для идемпотентности событий терминала, отзыв прав `UPDATE`/`DELETE` на журнале движений.
