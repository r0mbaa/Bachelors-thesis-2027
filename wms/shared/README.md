# shared

DTO, доменные типы-значения и контракты API, общие для `core` и `planner`.

Подключается обоими сервисами как обычная зависимость времени компиляции. Контракт описан **один раз**, дублирования DTO нет, рассогласование ловится компилятором, а не в рантайме (§12.2). Здесь же живут типы запросов и ответов планировщика из §12.4.
