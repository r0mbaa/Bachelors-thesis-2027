# engine.distance — матрица кратчайших расстояний

Матрица кратчайших расстояний между точками отбора батча и депо (FR-M8-02) и развёртывание маршрута в полный путь по графу (FR-M8-05).

Сам граф строит модуль `layout`: он нужен ещё и конструктору в `core` и стенду `research`, поэтому живёт в библиотеке, а не в сервисе (см. «Отступления от спецификации» в `wms/README.md`). Модель склада — §8.1, перечень задач построения графа — §8.7.

Ключ кэша включает версию планировки (§8.7, Д4).

**Замечание по A\* (§9.1):** на статичной топологии для матрицы по 30–60 точкам эффективнее многократный Дейкстра от каждой точки либо предрасчёт Флойд–Уоршеллом с кэшированием. A\* выигрывает только на отдельных парах при хорошей эвристике (манхэттенское расстояние).
