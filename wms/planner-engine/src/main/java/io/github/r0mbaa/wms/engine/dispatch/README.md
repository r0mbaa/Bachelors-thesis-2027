# engine.dispatch — M9. Диспетчеризация

Назначение заданий сборщикам. Постановка — §8.5, каталог методов — §9.3: FCFS, EDF, правило минимального холостого пробега, венгерский алгоритм / min-cost flow, скользящий горизонт с локальным поиском.

Состояние заданий — в модуле `core`, пакет `core.task`.

**Требования:** FR-M9-01 .. FR-M9-09, переключение правила конфигурацией — FR-M9-03.

Использует прогноз длительности задания (§10.1) вместо константной оценки, что напрямую влияет на выполнение cut-off.
