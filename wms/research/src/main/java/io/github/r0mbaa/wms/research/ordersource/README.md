# research/ordersource — источники заказов

Общий интерфейс `OrderSource` с реализациями: синтетический генератор, загрузчик открытого датасета (UCI Online Retail, Instacart), загрузчик выгрузки реального предприятия.

Замена источника не должна требовать изменений вне его реализации (FR-M14-09). Стратегия получения данных — §14.3.
