# research/generator — генератор топологий

Создаёт склады по параметрам: число проходов, длина прохода, число ярусов, число поперечных проходов, ширина прохода, положение депо.

FR-M14-01 и мастер типовой планировки FR-M15-09 описывают одну и ту же операцию, поэтому сам генератор прямоугольной планировки живёт в библиотеке `layout` и общий для конструктора и стенда. Здесь остаётся перебор параметров под план эксперимента: сетка по `k = L/d`, числу ярусов и т.д. (§14.2).

**Требования:** FR-M14-01.
