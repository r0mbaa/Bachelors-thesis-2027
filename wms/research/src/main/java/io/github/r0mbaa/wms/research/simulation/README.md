# research/simulation — имитационная модель сборки

Цикл дискретных событий над `PriorityQueue`. Реализуется самостоятельно: полноценный фреймворк уровня SimPy для данной задачи избыточен, объём — несколько сотен строк (§12.6).

Длительность задания вычисляется по явной формуле вида `T = L/v + n·t_pick + Σh(p) + ε`. Это ограничение существенно для ML-контура — см. §10.4 и README пакета `engine.slotting` в модуле `planner-engine`.
