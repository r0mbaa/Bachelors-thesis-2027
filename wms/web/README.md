# web — веб-панель

React 18, TypeScript, Vite, TanStack Query.

| Часть | Технология |
| --- | --- |
| Конструктор планировки | Canvas 2D или SVG собственного рендера, zustand для состояния редактора, отмена/повтор через журнал команд |
| Трёхмерная сцена | three.js, react-three-fiber, drei |
| Производительность | `InstancedMesh` для ячеек и стеллажей, ручные уровни детализации, frustum culling |
| Отрисовка маршрута | `Line2` либо `TubeGeometry` |

**Требования:** FR-M15-01 .. FR-M15-31 (M15). Серверная часть — [`core.layout`](../core/src/main/java/io/github/r0mbaa/wms/core/layout), геометрия (ячейки, граф, валидация) — библиотека [`layout`](../layout).

**Принцип разделения (§7.15.1):** редактирование только в 2D, отображение в 3D. Отдельная 2D-схема склада не создаётся — её роль выполняет вид сверху конструктора.

**По производительности:** без инстансирования склад в 100 тыс. ячеек не отрисовывается (NFR-P-07). Обычный `THREE.Line` имеет фиксированную толщину в пиксель и плохо читается на схеме, поэтому маршрут рисуется иначе.
