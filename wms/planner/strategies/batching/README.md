# planner/strategies/batching — M7. Батчинг

Объединение заказов в партии сборки с учётом вместимости тары. Постановка — §8.3, каталог методов — §9.2.

| Группа | Методы |
| --- | --- |
| Тривиальные | FCFS до заполнения тары (обязательный baseline «как есть»), случайное разбиение |
| Конструктивные | Seed-алгоритмы (Gibson & Sharp), Savings / Clarke–Wright |
| Кластеризация | Агломеративная с ограничением вместимости, k-medoids по маршрутным расстояниям, DBSCAN по центроидам |
| Метаэвристики | Генетический алгоритм, табу-поиск (Henn & Wäscher), ALNS |

**Требования:** FR-M7-01 .. FR-M7-08, переключение алгоритма конфигурацией — FR-M7-05.

**Замечание по k-means (§9.2).** Прямое применение к координатам товаров некорректно: заказ есть множество точек, а не точка, метрика в пространстве координат не отражает стоимость совместной сборки, ограничение вместимости не соблюдается. Корректные варианты — бинарный вектор посещаемых проходов с косинусной метрикой, k-medoids на матрице savings-расстояний, капацитированная кластеризация.
