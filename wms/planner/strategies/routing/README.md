# planner/strategies/routing — M8. Маршрутизация

Задача обхода сборщика (Picker Routing Problem), постановка — §8.2, каталог методов — §9.1.

| Группа | Методы |
| --- | --- |
| Базовые эвристики | Return, S-shape (основной baseline), Midpoint, Largest Gap, Combined, Aisle-by-aisle |
| Точные | Ratliff–Rosenthal DP (эталон оптимума для однозонной планировки), Roodbergen–de Koster DP, решатель TSP (OR-Tools / MTZ) |
| Метаэвристики | Nearest Neighbour и 2-opt / Or-opt, имитация отжига, генетический алгоритм, муравьиный алгоритм |

**Требования:** FR-M8-01 .. FR-M8-10, переключение алгоритма конфигурацией — FR-M8-03.

Инварианты маршрута проверяются property-based тестами на jqwik (§12.6): все требуемые точки без пропусков и дублей, старт и финиш в депо, заявленная длина равна сумме длин рёбер развёрнутого пути, длина не превышает S-shape на том же экземпляре.
