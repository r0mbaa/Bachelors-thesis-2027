# planner/strategies/slotting — M12. Слоттинг и аналитика

Рекомендации по перекладке товара. Каталог методов — §9.4.

| Метод | Комментарий |
| --- | --- |
| ABC-размещение по частоте отбора | Классика, сильный эффект при малых затратах |
| COI (Cube-per-Order Index) | `COI = объём хранения / частота отбора` |
| Корреляционное размещение | Кластеризация графа совместной встречаемости (Лувен / Label Propagation) |
| Ассоциативные правила | FP-Growth через SPMF |
| Прогноз спроса | Градиентный бустинг / SARIMA, упреждающее размещение |

**Требования:** FR-M12-01 .. FR-M12-10. **API:** `POST /api/v1/analytics/slotting` (§12.4).

**ML-контур (§10).** Основной компонент выбирается по доступности данных: при наличии реальной телеметрии — модель длительности задания (§10.1), иначе корреляционное размещение (§10.2) на реальной матрице совместной встречаемости из открытого датасета. Обучать супервизорную модель длительности на выходе симулятора методологически некорректно (§10.4): регрессия восстанавливает заложенную в симулятор формулу, а высокое `R²` отражает детерминированность данных, а не предсказательную силу.
