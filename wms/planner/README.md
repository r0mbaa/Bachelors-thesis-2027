# planner — сервис планирования

Spring Boot, Java 21. Stateless, CPU-bound, масштабируется горизонтально. Отказ деградирует до ручного формирования задания, а не останавливает склад (NFR-R-05).

**Основной предмет исследования**, поэтому частота изменений здесь высокая (§12.2).

| Пакет | Содержимое |
| --- | --- |
| [`graph/`](graph) | Графовая модель склада, матрица кратчайших расстояний, построение графа из планировки |
| [`strategies/`](strategies) | Реестр взаимозаменяемых алгоритмов |

## Реестр стратегий

Ключевой архитектурный приём (§12.3): реестр не пишется вручную — контейнер Spring внедряет все реализации интерфейса в `Map<String, RoutingStrategy>`, где ключ карты есть имя бина. Добавление алгоритма сводится к новому классу с `@Component`, ядро не меняется. Стенд экспериментов получает полный список стратегий из того же контейнера, без ручной регистрации.

**API:** §12.4 — `/api/v1/plan/route`, `/plan/batch`, `/plan/dispatch`, `/plan/replan`, `/analytics/slotting`, `GET /strategies`.

**Библиотеки:** JGraphT (Дейкстра, Флойд–Уоршелл, A\*, эвристики TSP), OR-Tools как эталонный решатель, SPMF, Smile или Tribuo.
