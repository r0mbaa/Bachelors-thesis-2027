# planner — сервис планирования

Spring Boot, Java 25. Stateless, CPU-bound, масштабируется горизонтально. Отказ планировщика деградирует систему до ручного формирования задания, но не останавливает склад (NFR-R-05).

Сервис — тонкая REST-обёртка: алгоритмы, матрица расстояний и реестр стратегий находятся в библиотеке [`planner-engine`](../planner-engine). Благодаря этому стенд `research` вызывает те же алгоритмы без HTTP (см. «Отступления от спецификации» в [`wms/README.md`](../README.md)).

**Основной предмет исследования**, поэтому код за этим сервисом меняется чаще всего (§12.2).

**API:** §12.4 — `/api/v1/plan/route`, `/plan/batch`, `/plan/dispatch`, `/plan/replan`, `/analytics/slotting`, `GET /strategies`.

**Порт по умолчанию:** 8081.
