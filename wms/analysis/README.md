| Библиотека | Назначение |
| --- | --- |

| scipy.stats | Критерий Уилкоксона, доверительные интервалы |
| matplotlib | Графики для пояснительной записки |

Вход — CSV из [`research/experiments`](../research/experiments). Полноценных аналогов этого уровня в Java нет, и воспроизводить их не нужно; при этом вынос на Python только анализа не порождает издержек разноязычных сервисов — нет общих моделей, контрактов и синхронизации DTO.
