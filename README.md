# Bachelor's thesis 2027

Выпускная квалификационная работа бакалавра, направление «Программная инженерия».

**Тема:** Программный модуль интеллектуального управления заданиями и маршрутизацией для складского предприятия.

Веб-система управления складом с адресным хранением на QR-кодах: размещение товара двумя сканированиями с телефона, объединение заказов в партии сборки с учётом вместимости тары и построение оптимальных маршрутов обхода склада.
